 Objectives

Analyze overall sales performance and revenue trends

Identify top-performing products and categories

Understand customer purchasing patterns

Evaluate outlet performance based on location and size

Provide data-driven insights for business decision-making


📊 Tools & Technologies Used

Power BI – Data visualization and dashboard creation

Excel / CSV – Data preprocessing and cleaning


📁 Dataset Description

The dataset includes:

Item details (type, fat content, category)

Outlet information (location, size, type)

Sales metrics (total sales, average sales, ratings)

📈 Key Insights

🥇 Identified top-selling product categories contributing the highest revenue

📍 Tier-wise outlet analysis revealed higher sales concentration in specific regions

🏬 Medium-sized outlets generated maximum overall sales

🧾 Low-fat items showed strong demand compared to regular items

⭐ Customer ratings positively influenced sales performanance
